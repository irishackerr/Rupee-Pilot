# Rupee-Pilot
Rupee Pilot is a desktop-based personal finance tracking application that helps users manage income, expenses, and savings. Built as an MVP using Python, Tkinter, and SQLite.
A desktop-based personal finance tracking application built with Python.

## Features
- Multi-user profiles
- Income & expense tracking
- Category and month filters
- Analytics dashboard
- Smart spending insights
- CSV export
- Dark professional UI

## Tech Stack
- Python
- Tkinter
- SQLite
